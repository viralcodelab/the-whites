## Проекты для портфолио

### 1. 🌐 Лендинг сайта салона красоты
**Файлы:** `index.html`, `style.css`, `script.js`

**Описание:**
Одностраничный сайт с полной информацией о салоне красоты "Аврора". Современный дизайн с градиентами и анимациями.

**Основные секции:**
- Hero-баннер с призывом к действию
- Каталог услуг (6 основных категорий)
- Галерея работ с плейсхолдерами
- Подробный прайс-лист по категориям
- Форма онлайн-записи
- Контактная информация
- Адаптивный дизайн для мобильных устройств

**Технологии:** HTML5, CSS3, Vanilla JavaScript

**Особенности:**
- Плавная прокрутка (smooth scroll)
- Анимации при скролле (Intersection Observer)
- Интерактивная форма записи
- Градиентные акценты в фирменном стиле
- Полностью адаптивная верстка

### 2. 🤖 Telegram-бот записи
**Файлы:** `bot/index.html`, `bot/bot-style.css`, `bot/bot-script.js`

**Описание:**
Интерактивный прототип Telegram-бота для записи клиентов в салон красоты. Имитирует реальный интерфейс мессенджера с пошаговым процессом бронирования.

**Функционал:**
1. Выбор услуги из 6 категорий
2. Выбор мастера с информацией об опыте
3. Выбор удобного времени
4. Подтверждение записи с итоговой информацией
5. Финальное сообщение с деталями бронирования

**Технологии:** HTML5, CSS3, JavaScript (ES6+)

**Особенности:**
- Стилизация под интерфейс Telegram
- Mockup телефона iPhone с notch
- Анимированные сообщения
- Пошаговая логика бронирования
- Сохранение данных о записи

**Мастера салона:**
- Анна Петрова (5 лет опыта)
- Елена Ковальчук (3 года опыта)
- Мария Сидорова (7 лет опыта)

### 3. 📋 Квиз для подбора ухода
**Файлы:** `quiz/index.html`, `quiz/quiz-style.css`, `quiz/quiz-script.js`

**Описание:**
Интерактивный квиз из 4 вопросов для персонального подбора косметологических процедур. Анализирует тип кожи, проблемы и цели клиента.

**Структура квиза:**
1. **Вопрос 1:** Тип кожи (сухая, жирная, комбинированная, нормальная)
2. **Вопрос 2:** Проблемы кожи (акне, возрастные изменения, пигментация, чувствительность)
3. **Вопрос 3:** Частота ухода (ежедневно, еженедельно, редко, не делаю)
4. **Вопрос 4:** Желаемый результат (увлажнение, омоложение, очищение, сияние)

**Результаты:**
- Основная рекомендованная процедура
- Дополнительные процедуры по проблеме
- Советы косметолога по частоте ухода
- Специальное предложение со скидкой 15%

**Технологии:** HTML5, CSS3, JavaScript

**Особенности:**
- Progress bar с отслеживанием прогресса
- Плавные анимации переходов
- Адаптивный дизайн
- Персонализированные рекомендации
- Расчет стоимости комплекса процедур
- Кнопка записи с переходом на главный сайт

## Как запустить проекты

### Лендинг:
1. Откройте `index.html` в браузере
2. Все стили и скрипты подключены локально

### Бот:
1. Откройте `bot/index.html` в браузере
2. Кликайте по кнопкам для прохождения процесса записи

### Квиз:
1. Откройте `quiz/index.html` в браузере
2. Ответьте на 4 вопроса для получения рекомендаций
