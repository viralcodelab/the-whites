# Telegram Bot для салона Аврора

## Установка

1. Установите зависимости:
```bash
npm install
```

2. Получите токен бота:
   - Напишите @BotFather в Telegram
   - Отправьте команду `/newbot`
   - Следуйте инструкциям
   - Скопируйте полученный токен

3. Откройте `bot.js` и замените `YOUR_BOT_TOKEN_HERE` на ваш токен

4. Запустите бота:
```bash
npm start
```

Или для разработки с автоперезагрузкой:
```bash
npm run dev
```

## Функции бота

✅ Интерактивный квиз для подбора услуги
✅ Выбор даты и времени записи
✅ Прайс-лист
✅ Контактная информация
✅ Подтверждение записи

## Структура квиза

1. **Опыт посещения салонов**
   - Регулярно
   - Иногда
   - Первый раз

2. **Желаемый результат**
   - Повседневный уход
   - Особый случай
   - Полное преображение

3. **Бюджет**
   - До 1000₽
   - 1000-2000₽
   - Более 2000₽
   - Не важно

4. **Удобное время**
   - Утро (10:00-12:00)
   - День (12:00-15:00)
   - Вечер (15:00-19:00)
   - Любое

На основе ответов бот рекомендует подходящие услуги!
